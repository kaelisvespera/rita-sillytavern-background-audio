# Rita 后台保活 · TT 安卓

面向 TauriTavern 安卓版的后台保活音频扩展，基于 [Rita 的 SillyTavern 扩展](https://github.com/rita090qwq/rita-sillytavern-background-audio)。

扩展默认在页面启动时尝试循环播放随包附带的低音量音频。音频被系统暂停时，回到酒馆会尝试恢复播放。播放状态显示在扩展面板和悬浮按钮上。

## 安装与使用

1. 在 TT 安卓版打开「扩展 → 安装扩展」，粘贴 `https://github.com/kaelisvespera/rita-sillytavern-background-audio`。如果之前通过 Rita 原仓库安装过同名扩展，先在「管理扩展」里卸载旧版，再用这个地址安装。
2. 在扩展面板打开「Rita 后台保活 · TT 安卓」查看状态。如果显示「等待自动播放」，点一下页面或保活按钮。出现「音频播放中」后再切换应用。也可以点聊天页右下方的扬声器浮球开关，绿色表示正在播放。
3. 用完点击「关闭保活」。如果回到酒馆后提示再次开启，点一下按钮重试。

千机伞可以收纳扬声器浮球。展开千机伞后，点收纳栏里的扬声器即可开关保活。已收纳过的浮球会沿用原来的收纳记录。

## 播放方式

- WAV 循环是默认模式，使用浏览器的音频播放器。
- Web Audio 是实验模式，在音频上下文中循环同一段音频。关闭保活后即可切换模式，已选模式会保存。
- 手动关闭的状态会保存。下次打开页面时继续保持关闭，直到你再次开启。

## 安卓后台行为

音频保活的实际效果取决于安卓系统和 WebView。锁屏、系统省电或其他应用抢占音频焦点时，音频可能中断。系统结束 TT 进程后，重新打开应用时会按保存的开关状态启动。

## 文件与许可

- `manifest.json` 注册扩展，`index.js` 管理起停和恢复，`style.css` 定义按钮及状态样式。
- `keepalive.wav` 是随包附带的两秒低振幅 PCM 音频。音量写入音频文件，播放器使用默认增益。
